# Archivo

Informes y planes de un día concreto. Se guardan por la historia --por qué se
decidió algo, qué se encontró aquella noche-- pero **no se mantienen**: lo que
dicen puede estar superado.

Lo vigente está en:

- `docs/MAPA-DEL-PROYECTO.md` — qué pantallas hay y dónde se configura cada cosa.
- `docs/RECORRIDOS.md` — lo que tiene que funcionar.
- `docs/REVISAR-A-OJO.md` — decisiones de producto y criterio visual pendientes.
- El GSheet del cliente — el estado de cada funcionalidad (Status), sus
  pruebas manuales (Tests) y los pedidos (Para Claude).

| Archivo | De qué es |
|---|---|
| `INFORME-NOCHE.md` | Trabajo de la noche del 23 al 24/09/2026 |
| `NAVEGADOR.md` | Lista de comprobaciones a mano en el navegador, 25/09/2026 (hoy lo hacen las pruebas de componentes y la pestaña Tests del GSheet) |
| `PLAN-CORRECCIONES.md` | Plan de la revisión del 13/10/2026 |
| `CORRECCIONES-14.10.v1.md` | Correcciones del 14/10/2026 |
| `CORRECCIONES-16.10.md` | Observaciones de M del 16/10/2026 |
